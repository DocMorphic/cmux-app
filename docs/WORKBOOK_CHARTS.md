## Source and implementation

Scoped iOS `ChatArtifactPreviewRouter.swift` at
`f4b1509054949eaad5d695569ad443c4c18ed68d` still routes recognized binary
content to Quick Look after image/PDF/media/Markdown/text, subject to runtime
admission. Cached source SHA-256:
`e20371818593f22f028a474c608dc11b71f1b373d31dfdc36d2af880596c599c`.
This is routing evidence; it does not prove Quick Look renders every chart
variant. The global parity pin is unchanged.

The XLSX reader now projects typed worksheet/drawing/chart relationships from
its validated, independently owned workbook snapshot. One-cell, two-cell and
absolute anchors share the existing cell geometry and sparse range calculation.
Charts extend navigable ranges, including empty sheets containing only charts.
Images and charts retain their source drawing order. Existing image-only
callers keep their API and all picture tests remain in the integration.

`workbook-charts.js` adapts the unmodified, pinned presentation renderer 1.3.0's
public `buildPresentation` input and calls its actual chart rendering pipeline.
Chart XML and resources retain their package paths; only the minimal presentation,
slide, layout and master wrapper is generated in memory. There is no second
renderer copy, synthetic ZIP or upload. The exact `chart-renderer.js` asset alias
serves the already pinned presentation bundle through the existing same-origin
allowlist; no arbitrary path is admitted.

- Authored numeric/string caches are retained. Missing caches can use bounded
  local worksheet row/column references, including escaped quoted Unicode sheet
  names. Uncached text categories emitted as `numRef` become literal string
  caches. Source XML is cloned and remains unchanged. External data is never
  opened; missing external/named/unsupported references are reported as omitted.
- Typed internal chart-style/color-style/theme/override resources are retained.
  The workbook theme follows its actual relationship, including nonstandard
  filenames; unused theme files are not selected. External or ambiguous theme
  relationships cannot silently choose a different theme.
- Each XML part is capped at 2 MiB; chart structure at 50,000 descendants,
  64 series and 16,000 actual/allocated points. A local reference is capped at
  10,000 cells. Per-chart original resources are capped at 8 MiB and shared
  original resources at 32 MiB. The shared drawing admission limit is 256 objects.
- Only charts intersecting the selected cell window mount. Render handles are
  disposed before sheet/window/geometry changes and on page exit. Canvas CSS
  dimensions are capped at 2048 per axis with preserved aspect ratio, and the
  selected window has a 16 Mi CSS-pixel aggregate budget. These are not measured
  device-memory limits; DPR and large-workbook performance remain to be checked.
- Omitted or failing drawing content retains the original-file notice and shared
  Open/Share/Save actions. The WebView denies external fetches and serves only
  known bundled assets plus its owned document.

Relationships are grounded in the primary
[Open XML chart reference documentation](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.drawing.charts.chartreference?view=openxml-3.0.1).
The engine's shipped parser and public exports were inspected locally. The
renderer license and pinned hash remain in the existing presentation inventory.

## Open acceptance

This batch does not establish full Quick Look rendering parity. Advanced chart
variants/combinations/3D, richer styles, named/dynamic formula references, other
drawing objects, shapes/effects, conditional formatting, chart interaction and
large-workbook performance need comparison and implementation where applicable.
Physical Pixel/Mac, actual file/provider routes, Activity/process restoration,
zoom/rotation, TalkBack and matched iOS screenshots remain open. The fixture uses
Compose saved-state restoration, not actual process death. These gaps are not
declared unavoidable platform differences. Signed milestone 642 predates charts;
charts currently belong to the subsequent debug source batch.
