# Original sign-in methods UI reference

The generator pins whole upstream files/package trees and inserts unchanged original
SignInView body/methods/card/brand/provider/error declarations into a methods-only
host. The original provider enum, restore-status view and rendering/input helpers
execute with UIKit/SwiftUI and the actual mobile support package. A small authored
auth service supplies idle, loading and restoring state without credentials,
auth SDKs or network. This measures UI, not production authentication.

The disposable CI simulator runs the actual compositor and public accessibility
controls. Paired exports require exact PNG hashes, traits, languages, original
source/template/generator hashes and a clean capture commit. Android uses the
upstream web Apple mark rather than redistributing a system symbol. The reference
does not establish whole-app, account, browser, device or final visual parity.
